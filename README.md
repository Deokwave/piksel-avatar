# piksel-avatar

Profilimizdeki 32x32 piksel avatarı çizen Python betiği. Karakter kodla, katman katman çiziliyor: arka plan, kapüşonlu, saç, yüz, kâkül, gözler ve en son kulaklık. Mor gece gökyüzü ve yıldızlar da betiğin içinde.

```
pip install pillow
python avatar.py avatar.png avatar-buyuk.png
```

İlk dosya 32x32, ikincisi büyütülmüş hali. Büyütme varsayılan olarak 16 kat; üçüncü değerle değiştirebilirsin: `python avatar.py avatar.png avatar-buyuk.png 8`.
